# Changelog

## 1.0.0 (2026-10-25)

### Added

- AI 中台：OpenAI 兼容模型接入、Mock 兜底、模型配置加密存储、调用用量记录。
- 会话智能分析：摘要、需求、异议、预算、决策人、承诺、下一步与意向等级。
- 客户标签建议：基于会话证据推荐标签，支持人工采纳并写回客户档案。
- 跟进建议：生成下一步动作，支持一键写入跟进记录。
- 智能质检：可配置规则、异步质检任务、命中证据、人工复核与统计概览。
- 版本化 Prompt：摘要与质检模板可在线编辑，保存自动递增版本。
- 私域业务骨架：线索、客户、跟进、订单（合同）、经营报表与组织权限。
- 细粒度权限：AI 设置、质检规则维护通过独立权限点控制。
- 本地一键依赖：Docker Compose 启动 MySQL 8 与 Redis 7。

### Security

- 模型 API Key 使用 AES 加密后入库，接口只返回掩码。
- 登录验证码、JWT 鉴权、角色权限与数据范围过滤。
- 敏感配置通过环境变量注入，仓库不包含真实密钥。
